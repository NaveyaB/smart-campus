A **Smart Campus (College Management System)** designed to manage and digitalize campus activities such as **student management, staff records, courses, attendance, and academic results**.

This project demonstrates **Full Stack Web Development** concepts including **API development, database management, and frontend integration**.

# ⚙️ Installation

### 1️⃣ Clone the repository

```
git clone https://github.com/NaveyaB/smart-campus.git
```

### 2️⃣ Navigate to project folder

```
cd smart-campus
```

### 3️⃣ Install backend dependencies

```
npm install
```

### 4️⃣ Run the server

```
node server.js
```

Server will start on:

```
http://localhost:5000
```
